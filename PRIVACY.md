# Nexus Chat Privacy Notice

Last updated: July 17, 2026

Nexus Chat is an independent community project for Survev and Resurviv.

## Data processed

Nexus Chat processes the information required to provide its social features:

- game display name;
- Nexus account ID and public friend code;
- profile avatar URL and biography;
- friendships and pending friend requests;
- Global messages, direct messages, reactions, and message timestamps;
- temporary connection, room, typing, poll, and presence information.

The recovery key is stored in your browser. The server stores a SHA-256 hash of that key, not the raw recovery key. Do not share the recovery key with anyone.

## Storage and retention

Persistent social data is stored in Turso. Global history is limited to the latest 100 messages. Direct-message history is limited to the latest 100 messages per conversation. Match chat, presence, typing, polls, and pins are temporary and may disappear when a room or server process ends.

## Sharing

Nexus Chat does not sell personal data and does not contain advertising trackers. Public profile fields and Global messages are visible to other Nexus users. Direct messages are available only to the participants, but they are stored by the service so conversations can be restored.

Infrastructure providers such as Render and Turso process data only as needed to host the service.

## Controls

You can change your public profile, remove friends, block users locally, clear local browser data, and stop using Nexus Chat at any time. There is currently no automated account-deletion screen. For a deletion request or privacy question, contact the project through the official Nexus Chat Discord linked on the website.

## Security

No internet service can guarantee absolute security. Keep your recovery key private and report suspected vulnerabilities responsibly as described in `SECURITY.md`.

This notice may be updated when the service changes. The current version will remain available with the project and website.
